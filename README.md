Welcome to the official repository for the **PeakStone** website. PeakStone is a premium digital agency that merges visionary design, relentless engineering, and adaptive AI to launch digital products that dominate their markets.

This website was built to reflect the elite, high-tech nature of the brand, utilizing a deeply immersive **Obsidian Summit & Glacial Emerald Design**.

## ✨ Features

- **Peak Precision Reticle Cursor**: A custom dual-layer cursor featuring a zero-latency center targeting bead paired with a smooth-inertial geometric reticle that expands, illuminates, and brackets interactive buttons and cards with a radiant emerald aura.
- **Obsidian & Glacial Summit Aesthetic**: A modern dark-mode palette featuring deep obsidian slate (`#07090E`), dark granite surfaces, luminous Alpine Cyber Emerald (`#00F5A0`), and Glacial Summit Cyan (`#00D9F5`).
- **Advanced Interactivity**:
  - **3D Monolith Tilt**: Service and technology cards physically tilt in 3D space with subtle light refraction sheens based on mouse position.
  - **Magnetic Buttons**: Call-to-action buttons subtly pull toward the user's cursor with fluid spring physics.
- **Premium Typography**: Uses Google Fonts `Syncopate` and `Outfit` for an architectural, high-end tech feel.
- **Topographic Elevation Backdrop**: An animated elevation grid matrix with sweeping emerald and cyan summit light cones.
- **Responsive Layout**: Fully optimized for Desktop, Tablet, and Mobile devices with a custom mobile navigation menu.

## 🛠️ Technology Stack

This project is built using **Vanilla Web Technologies** to ensure maximum performance and seamless deployment without the need for complex build tools.

- **HTML5**: Semantic and accessible structure.
- **CSS3**: Advanced features including `backdrop-filter` (glassmorphism), CSS animations, CSS Variables, and Grid/Flexbox layouts.
- **JavaScript (ES6)**: Lightweight logic for intersection observers (scroll reveal), 3D tilt math, cursor tracking, and mobile menus.

## 🚀 Deployment (GitHub Pages)

This project is 100% ready to be deployed to GitHub Pages out-of-the-box. 

1. **Fork or Clone** this repository.
2. Push the files to your own GitHub repository.
3. Navigate to your repository's **Settings** > **Pages**.
4. Under "Build and deployment", select the `main` branch as your source.
5. Save, and your futuristic tech site will be live within minutes!
